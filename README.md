# Snac-Man
A Pac-Man-inspired maze game built with Python and Pygame.

Snac-Man was originally created as an A-level Computer Science project. This version is a substantial refactor of the original codebase, with a focus on improving its structure, readability, maintainability, and test coverage.

## Features

* Five playable levels with increasing difficulty
* Four enemy types with different behaviours
* Randomly generated mazes
* Collision detection with enemies and maze walls
* Lives and score system
* Time-based bonus points
* A timed final level
* Automated tests using pytest

## Requirements

Python 3.10 or later is required.

Install the required dependencies with:

```bash
python -m pip install -r requirements.txt
```

## Running the game

From the project root, run:

```bash
python -m snacman
```

## Running the tests

Run the test suite with:

```bash
python -m pytest
```
